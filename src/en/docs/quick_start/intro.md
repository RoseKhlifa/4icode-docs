## Overview

**4i.codes** is an AI API gateway for developers. It provides unified access to major model families with stable routing and transparent usage-based billing.

One API key can cover GPT, Claude, Gemini, Grok, and other available models. The gateway supports OpenAI- and Anthropic-compatible protocols, so most tools can be connected in a few minutes.

## Why use 4i.codes?

- **Stable routing:** Multi-node routing with automatic failover and a target SLA above 99.9%.
- **Broad model coverage:** Access GPT, Claude, Gemini, and Grok families from one account.
- **Transparent billing:** Inspect token usage and charges for every request.
- **Native compatibility:** Use `/v1/responses`, `/v1/chat/completions`, and `/v1/messages`.
- **Fast connectivity:** Accelerated endpoints designed for reliable global access.
- **Technical support:** Support is available for integration, accounts, and billing.
