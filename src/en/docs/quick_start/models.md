## Find available endpoints and models

1. Open **Model Plaza** in the console.
2. Select a service group to review its available endpoints and model names.
3. Copy the Base URL from the selected group when configuring a compatible client.

![](/assets/image/quick_start/rc-3.webp)

Model availability and pricing can change. Use the console as the source of truth when selecting a model.
