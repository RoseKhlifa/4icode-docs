## Common setup checklist

Complete these steps before configuring a client:

1. Create an API key for the service group you need.
2. Copy the exact API Base URL shown in the console or documentation.
3. Select a model available to that key and service group.
4. Put the key in an environment variable or local configuration file.
5. Restart the client after changing its configuration.

::: tip
When an integration fails, check the Base URL, API key, service group, and model name first. These account for most setup issues.
:::
